# Cybersecurity Beginner Python Projects

A collection of beginner-friendly cybersecurity projects written in Python. These projects are designed to help learners understand important cybersecurity concepts such as encryption, password security, brute-force attacks, packet sniffing, and log analysis through simple hands-on examples.

---

# 📂 Project Categories

## 🔐 Encryption & Hashing

Projects related to basic encryption techniques and secure hashing methods.

### Caesar Cipher
Encrypts and decrypts messages using the Caesar cipher technique.

### Hashing Using SHA-256
Demonstrates secure hashing using the SHA-256 algorithm.

### Password Strength Checker
Evaluates password complexity and checks password strength.

---

## 🌐 Network Security

Projects focused on network analysis and security testing.

### Packet Sniffer
Captures network packets for monitoring and analysis purposes.

### Simple Port Scanner
Scans systems for open network ports.

### Wordlist Generator
Generates custom wordlists for security testing and educational purposes.

---

## 🔑 Authentication Security

Projects related to password security and authentication mechanisms.

### Brute Force Attack Simulator
Simulates password brute-force attacks for educational understanding.

### Password Checker
Checks password strength and verifies breached passwords.

### Simple Keylogger
Logs keystrokes for ethical cybersecurity research and awareness.

---

## 📊 Log Analysis & Detection

Projects focused on analysing logs and monitoring system activity.

### Log Analysis
Parses and analyses system logs for security monitoring.

### File Integrity Checker
Detects unauthorized or suspicious file modifications.

---

## 🚨 Threat Detection

Projects related to identifying and detecting potential threats.

### Email Spoof Detector
Parses and detects spoofing attempts across multiple email headers in a single file.
